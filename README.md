# Privacy Policy

BakeryApp does not collect, store, sell, or share personal information.

The app does not require users to create an account and does not transmit personal data to the developer.

BakeryApp may download publicly available information from files hosted on GitHub. This request is used only to display app content and does not include personal information from the user.

If this changes in a future version, this privacy policy will be updated before the new version is released.
